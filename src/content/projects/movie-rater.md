A full-stack web application demonstrating modern API-first architecture with an Angular single-page application frontend consuming a Django REST Framework backend API.

## Features

- User authentication and authorization
- Movie database with search and filtering
- Star rating system
- User reviews and comments
- RESTful API design
- Responsive UI

## Frontend (Angular)

- TypeScript-based Angular application
- Component-based architecture
- HTTP client for API communication
- Reactive forms for user input
- Material Design UI components

## Backend (Django REST Framework)

- Python-based REST API
- Token-based authentication
- Serializers for data validation
- ViewSets for CRUD operations
- PostgreSQL database integration
- OpenAPI documentation

## Learning Outcomes

This project demonstrates:
- Modern full-stack development patterns
- API-first architecture
- Frontend-backend separation
- Authentication and authorization flows
- RESTful API best practices
