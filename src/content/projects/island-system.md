A private educational web application demonstrating modern cloud architecture patterns including enterprise authentication, cross-device progress tracking, and mobile-first responsive design.

## Purpose

Built as a personal family project to provide secure, accessible educational content with professional-grade authentication and data persistence across multiple devices.

## Key Technical Features

- **Azure AD Authentication**: Microsoft account integration for secure access
- **Cloud Database**: Azure SQL for reliable progress tracking
- **PDF Export**: Dynamic PDF generation for offline study
- **Progress Tracking**: Cross-device learning progress synchronization
- **Mobile-First Design**: Responsive layouts for phones, tablets, and desktop
- **Progressive Web App**: Offline capability and app-like experience
- **Mathematical Rendering**: KaTeX integration for formula display
- **Dark Mode**: User preference persistence

## Architecture Highlights

**Authentication & Security**
- Microsoft Azure AD OAuth2 integration
- Session management and user tracking
- Login-required content protection
- Secure credential management

**Cloud Infrastructure**
- Flask application hosted on Heroku
- Azure SQL Database backend
- Cross-origin authentication flows
- Multi-device session handling

**Frontend Technologies**
- Mobile-responsive CSS layouts
- Interactive JavaScript features
- KaTeX for mathematical typography
- Mermaid for concept diagrams

## Learning Outcomes

This project demonstrates:
- Enterprise authentication patterns with Azure AD
- Cloud database integration (Azure SQL)
- Secure multi-tenant application architecture
- PDF generation from web content
- Progressive web app capabilities
- Mobile-first responsive design
- Session and state management

## Technical Implementation

Built with Python Flask framework, featuring Azure cloud service integration, modern authentication patterns, and responsive design principles. Deployed on Heroku with Azure SQL backend for reliable, accessible education delivery.
