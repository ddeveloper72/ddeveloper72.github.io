# README

## [Duncan Falconer Portfolio](https://ddeveloper72.github.io/)

Personal professional portfolio website showcasing healthcare interoperability and technical architecture expertise.

## Tech Stack

- **Astro** - Static site generator
- **Sass/SCSS** - Styling
- **Markdown/MDX** - Content
- **TypeScript** - Type safety

## Development

```bash
# Install dependencies
npm install

# Start dev server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```

## Project Structure

```
src/
  ├── components/       # Reusable UI components
  ├── content/          # Content collections (projects, case studies, timeline)
  ├── layouts/          # Page layouts
  ├── pages/            # Route pages
  ├── styles/           # Sass/SCSS files
  └── assets/           # Images and static assets
```
