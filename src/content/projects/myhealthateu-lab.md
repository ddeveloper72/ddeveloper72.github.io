An interactive learning environment demonstrating MyHealth@EU cross-border healthcare data exchange principles, including Patient Summary and ePrescription services.

## Overview

This project provides hands-on tools for understanding European healthcare interoperability standards and implementations.

## Key Components

- Interactive FHIR and CDA document viewers
- Patient Summary generation and validation
- ePrescription workflow demonstrations
- Standards compliance testing tools

## Educational Focus

Designed to help healthcare IT professionals understand:
- Cross-border data exchange patterns
- Patient Summary structure and content
- FHIR and CDA transformation workflows
- European eHealth infrastructure

## Technical Stack

Frontend built with Angular for interactive demonstrations, backend provides API services and validation logic using Flask and Python.
